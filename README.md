# 🏥 ENCS3340: Medical Test Management System in MIPS Assembly

## 📌 Overview
This repository contains my implementation of **Project #1: Medical Test Management System** for the **Computer Architecture** course at **Birzeit University**. The project involves developing a **MIPS assembly-based** system to efficiently store, manage, and retrieve medical test data for individual patients.

## 🛠 Features
- ✅ **Store and Manage Medical Tests**
- ✅ **Search Tests by Patient ID**
- ✅ **Retrieve Tests in a Specific Period**
- ✅ **Identify Abnormal Test Results**
- ✅ **Calculate Average Test Values**
- ✅ **Update and Delete Test Records**
- ✅ **Error Handling and Data Validation**

## 📂 Contents
- 📜 **Source Code:** MIPS assembly implementation of the medical test management system.
- 📝 **Test Cases:** Sample input and expected output.
- 📄 **Documentation:** Explanation of system functionality, validation rules, and error handling mechanisms.

## 🚀 How to Use
1. Clone the repository:
   ```bash
   git clone https://github.com/SajaAsfour/Medical-Test-Management-System-Using-MIPS-assembly
   ```
2. Load the **MedicalTest.asm** file into a MIPS simulator (e.g., **MARS**).
3. Run the program and interact with the text-based menu.
4. Input medical test records and execute various search/update operations.
5. Validate system responses against provided test cases.

## 📌 Requirements
- MIPS Simulator (**MARS**)
- Medical test dataset (text file)
